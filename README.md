# Studflow

## Регистрация в боте, первое сообщение от бота - просьба ввести название вуза

1. Пользователь вводит название своего вуза, ответным сообщением бот выдает inline кнопки с подходящими названиями вузов
2. После выбора вуза пользователю прилетает вопрос студент он или представитель какого либо отделения вуза
3.1 Студент должен ввести фио, номер группы, курс
3.2 Представитель вуза должен ввести название своего отделения 

## использование бота студентом

1. При заходе в бота студент с помощью команды / reply кнопки / написав слово старт получает ответное сообщение с вопросом какой именно отдел вуза его интересует. Выдаются inline кнопки с отделами, представители которых уже зарегестрировались в боте
2. Студент вводит сообщение для выбранного отдела

## Использование бота со стороны вуза

1. При заходе в бота человек который регистрировался от имени своего отделения видит сообщение "пока нет новых обращений", в сообщении также содержится inline кнопка для поиска студентов если конкретному отделу понадобится достучаться до кого либо, поиск осуществляется по ФИО

2. Если отделу прилетает сообщение от студента, сообщение об этом получает представитель. Сообщение студента либо изначально содержится в уведомлении о новом обращении, либо уведомление содержит inline кнопку при нажатии на которую выдается сообщение студента. Уведомление также содержит фио и прочие данные студента указанные при регистрации. После этого бот уточняет что представитель может написать свой ответ в чат

3. Представитель пишет ответ сообщением

4. Студент получает ответ представителя в том же формате в котором представитель получал сообщение студента, с поправкой на то что вместо данных студента в уведомлении должен отображаться отдел который написал студенту
